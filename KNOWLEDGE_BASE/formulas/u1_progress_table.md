# جدول التقدم وكميات الأنواع

للتفاعل $aA + bB = cC + dD$:

| | aA | bB | cC | dD |
|---|---|---|---|---|
| x=0 | n₀(A) | n₀(B) | 0 | 0 |
| x | n₀(A)−a·x | n₀(B)−b·x | c·x | d·x |
| x_max | n₀(A)−a·x_max | n₀(B)−b·x_max | c·x_max | d·x_max |

تقدم الأعظمي (المتفاعل المحدّ):

$$x_{max} = \min\left(\frac{n_0(A)}{a},\ \frac{n_0(B)}{b}\right)$$
