# النشاط الإشعاعي

عدد التفككات في الثانية:

$$A(t) = -\frac{dN}{dt} = \lambda.N(t)$$

تطور النشاط:

$$A(t) = A_0\,e^{-\lambda t} \qquad A_0 = \lambda.N_0$$

الوحدة: بكريل Bq (1 Bq = تفكك/ثانية).
