# المعايرة اللونية واستغلالها

عند التكافؤ: كمية المادة المنفعلة وفق الستوكيومترية للمعايرة:

$$n_A(équ) = n_B(équ)/\text{معامل} \qquad C_A = \frac{C_B.V_B(équ)}{V_A}$$

## استغلال بياني

- الطريقة الفارقية: $\frac{\Delta pH}{\Delta V}$ حوله قيمة قصوى عند V_équ.
- طريقة المماسين المتوازيين لمنحنى pH = f(V).

## عند منتصف المعايرة (حمض ضعيف + أساس قوي)

$$pH = pK_a \qquad (\text{لنبقى الحمض والغالبة: } [HA] = [A^-])$$
