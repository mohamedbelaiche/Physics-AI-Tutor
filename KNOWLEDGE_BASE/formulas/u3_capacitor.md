# علاقة المكثفة وسعتها

العلاقة الأساسية:

$$Q = C \cdot U \qquad C = \frac{Q}{U}$$

تجميع المكثفات:

- تفرع: $C_{éq} = C_1 + C_2$
- تسلسل: $\frac{1}{C_{éq}} = \frac{1}{C_1} + \frac{1}{C_2}$

أجزاء الفاراد: 1 µF = 10⁻⁶ F؛ 1 nF = 10⁻⁹ F؛ 1 pF = 10⁻¹² F.
