# دور القمر الاصطناعي وعلاقة r³/T²

الدور:

$$T = \frac{2\pi r}{v} = 2\pi\sqrt{\frac{r^3}{G.M_T}}$$

ثابت حركة القمر (حالة قمرية):

$$\frac{(R_T + h)^3}{T^2} = G\frac{M_T}{4\pi^2} = K$$

## شروط القمر الجيومستقر

1. جهة الدوران = جهة دوران الأرض (غرب → شرق).
2. المدار في مستوى خط الاستواء.
3. الدور = دور الأرض.
4. الارتفاع ≈ 36000 km.
