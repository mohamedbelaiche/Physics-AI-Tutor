# حركة القذيفة

المعادلات الزمنية (بدون الهواء):

$$x = v_0\cos\alpha\,.t \qquad z = -\frac{1}{2}g.t^2 + v_0\sin\alpha\,.t$$

معادلة المسار:

$$z = -\frac{g}{2v_0^2\cos^2\alpha}x^2 + \tan\alpha\,.x$$

النقاط الخاصة:

$$t_s = \frac{v_0\sin\alpha}{g} \qquad z_s = \frac{v_0^2\sin^2\alpha}{2g} \qquad x_p = \frac{v_0^2\sin 2\alpha}{g}$$

- x_p = 2x_s؛ المدى أعظمي عند α = 45°.
