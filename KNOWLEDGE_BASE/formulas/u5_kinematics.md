# معادلات الحركة المستقيمة المتغيرة بانتظام

$$v(t) = a.t + v_0$$

$$x(t) = \frac{1}{2}a.t^2 + v_0.t + x_0$$

الاتجاه: a=0 منتظمة؛ a·v > 0 متسارعة؛ a·v < 0 متباطئة.
