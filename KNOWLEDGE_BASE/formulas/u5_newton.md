# قوانين نيوتن

الأول: $\sum \vec{F}_{ext} = \vec{0} \Leftrightarrow \vec{v}_G = \overrightarrow{Cte}$.

الثاني:

$$\sum \vec{F}_{ext} = m.\vec{a}_G$$

الثالث: $\vec{F}_{A/B} = -\vec{F}_{B/A}$ (مبدأ الفعلين المتبادلين).
