# ثابت الزمن لثنائي القطب RL

$$\tau = \frac{L}{R + r}$$

بيعي: $\left[\frac{L}{R+r}\right] = [T]$.

التعيين البياني بطرق % أو المماس عند t = 0 أو ≈ 5τ للنظام الدائم (نفس المنهجية المسابقة RC).
