# السرعة الحجمية واللحظية للتفاعل

السرعة اللحظية: الانحدار

$$v(t) = \frac{dx}{dt}\Big|_t$$

السرعة الحجمية:

$$v_{vol}(t) = \frac{1}{V_T}\,\frac{dx}{dt}\Big|_t$$

العلاقة مع سرعات تكوّن/اختفاء الأنواع:

$$v = \frac{1}{a}v_A = \frac{1}{b}v_B = \frac{1}{c}v_C = \frac{1}{d}v_D$$
