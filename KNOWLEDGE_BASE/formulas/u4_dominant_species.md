# علاقة هندرسون-هاسيلبالخ والصفة الغالبة

$$pH = pK_a + \log\left(\frac{[A^-]_f}{[HA]_f}\right)$$

| الشرط | الغلبة |
|---|---|
| pH < pKa | حمضية ([HA] > [A⁻]) |
| pH = pKa | لا غلبة ([HA] = [A⁻])، τf = 1/2 |
| pH > pKa | أساسية ([A⁻] > [HA]) |
