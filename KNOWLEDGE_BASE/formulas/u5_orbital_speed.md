# سرعة الدوران للمدار الدائري

كوكب حول الشمس ($M_S$):

$$v = \sqrt{G\frac{M_S}{r}}$$

قمر اصطناعي حول الأرض ($h$):

$$v = \sqrt{G\frac{M_T}{R_T + h}}$$

التسارع الناظمي في الحركة الدائرية المنتظمة:

$$a_N = \frac{v^2}{r}$$
