## الشريحة 1 — بنية جدول التقدم
<type>: table
<layout>: full
<scene>?: no

| معادلة التفاعل | aA | + | bB | = | cC | + | dD |
|---|---|---|---|---|---|---|---|
| **الحالة الابتدائية** (x=0) | n₀(A) | | n₀(B) | | 0 | | 0 |
| **الحالة الانتقالية** (x) | n₀(A) − a·x | | n₀(B) − b·x | | c·x | | d·x |
| **الحالة النهائية** (x_max) | n₀(A) − a·x_max | | n₀(B) − b·x_max | | c·x_max | | d·x_max |

> التفاعلات المدروسة في هذه الوحدة كلها **تامّة**: التقدم الأعظمي x_max = التقدم النهائي x_f.

## الشريحة 2 — المتفاعل المحدّ
<type>: scene
<layout>: two-col
<scene>?: yes

المتفاعل المحدّ هو **الذي تنتهي كمية مادته أولًا** قبل بقية المتفاعلات. نحسب x_max لكل متفاعل:

$$n_0(A) - a \cdot x_{max} = 0 \implies x_{max} = \frac{n_0(A)}{a}\ (mol)$$

$$n_0(B) - b \cdot x_{max} = 0 \implies x_{max} = \frac{n_0(B)}{b}\ (mol)$$

**القيمة الصغرى** لـ x_max هي التي تحدد المتفاعل المحدّ.

## الشريحة 3 — المزيج الستوكيومتري
<type>: text
<layout>: full
<scene>?: no

المزيج **ستوكيومتري** عندما يكون:

$$\frac{n_0(A)}{a} = \frac{n_0(B)}{b}$$

(أي يتساوى x_max للمتفاعلين — لا يوجد متفاعل محدّد في هذه الحالة.)

## الشريحة 4 — الحصيلة المولية والتركيز المولي عند t
<type>: formula
<layout>: full
<scene>?: no

عند الحالة النهائية:

$$n_f(A) = n_0(A) - a \cdot x_{max} \quad , \quad n_f(C) = c \cdot x_{max}$$

$$[A]_f = \frac{n_0(A) - a \cdot x_{max}}{V_T} \quad , \quad [C]_f = \frac{c \cdot x_{max}}{V_T}$$

عند t₁/₂: بنفس الطريقة مع $x(t_{1/2}) = \frac{x_{max}}{2}$.

> لا تنسَ حساب شوارد الفضّة المتفرّجة (تبقى ثابتة لأنها لم تشارك).
