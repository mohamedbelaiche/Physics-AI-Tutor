# جدول التقدم

## البنية

للتفاعل $aA + bB = cC + dD$:

| | aA | bB | cC | dD |
|---|---|---|---|---|
| ابتدائية (x=0) | n₀(A) | n₀(B) | 0 | 0 |
| انتقالية (x) | n₀(A) − a·x | n₀(B) − b·x | c·x | d·x |
| نهائية (x_max) | n₀(A) − a·x_max | n₀(B) − b·x_max | c·x_max | d·x_max |

## المتفاعل المحدّ

القيمة الأصغر لـ x_max (المحسوبة لكل متفاعل: x_max = n₀/معامله) تحدد المتفاعل المحدّ.

## المزيج الستوكيومتري

تحقق الشرط $\frac{n_0(A)}{a} = \frac{n_0(B)}{b}$؛ تختفي كل المتفاعلات معًا.

## ملاحظة

في هذه الوحدة التفاعلات المدروسة **تامّة**، إذن x_max = x_f. حصيلة المادة والتركيز المولي عند أي لحظة (بما فيه t₁/₂) تُستخرج مباشرة من الجدول.
