# الحركة الدائرية — قمر اصطناعي وكوكب

## الحركة الدائرية المنتظمة

المسار دائري وقيمة السرعة ثابتة؛ تسارع ناظمي $a_N = \frac{v^2}{r}$؛ الدور:

$$T = \frac{2\pi r}{v}$$

كل جسم في حركة دائرية منتظمة له **تسارع مركزي (ناظمي)**.

## قانون التجاذب الكوني

$$F_1 = F_2 = G\frac{m_1.m_2}{d^2} \qquad G = 6.67\times 10^{-11}\ N.m^2.kg^{-2}$$

## كوكب حول الشمس (مرجع هيليومركزي)

بالقانون II: $\vec{a} = G\frac{M_S}{r^2}\vec{n}$ ناظمي ⇒ حركة دائرية منتظمة (a_t = 0، v = Cte).

$$v = \sqrt{G\frac{M_S}{r}} \qquad T = 2\pi\sqrt{\frac{r^3}{G.M_S}}$$

## قمر اصطناعي حول الأرض (مرجع جيومركزي)

$$\frac{(R_T+h)^3}{T^2} = G\frac{M_T}{4\pi^2} = K \ (\text{ثابت})$$

### شروط القمر الجيومستقر

1. جهة دوران = جهة دوران الأرض (غرب→شرق).
2. مداره على مستوى خط الاستواء.
3. دورانه = دوران الأرض.
4. ارتفاع ≈ 36000 km.

### الجاذبية على ارتفاع h

$$g = g_0\frac{R_T^2}{(R_T+h)^2}$$
