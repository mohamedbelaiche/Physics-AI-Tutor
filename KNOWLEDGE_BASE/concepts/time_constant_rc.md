# ثابت الزمن τ لثنائي القطب RC

## التعريف

$$[R.C] = [T] \qquad \tau = R.C$$

وحدة τ: الثانية.

## التعيين البياني

1. **طريقة 63%/37%:** الشحن: u_C(τ) ≈ 0.63E؛ التفريغ: u_C(τ) ≈ 0.37E.
2. **طريقة المماس عند t = 0:** المماس يقطع المستقيم الحدّي عند t = τ.
3. **نهاية النظام الانتقالي:** t ≈ 5τ تكتمل فيه التبادلات تقريبًا.
