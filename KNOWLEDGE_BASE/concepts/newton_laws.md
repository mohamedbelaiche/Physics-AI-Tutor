# قوانين نيوتن

## الأول — مبدأ العطالة

في مرجع غاليلي: الجملة المعزولة/شبه المعزولة تحافظ على سكونها أو حركتها المستقيمة المنتظمة:

$$\left(\sum \vec{F}_{ext} = \vec{0}\right) \Leftrightarrow \vec{v}_G = \vec{0} \ \text{أو} \ \vec{v}_G = \overrightarrow{Cte}$$

## الثاني — المبدأ الأساسي للتحريك

$$\sum \vec{F}_{ext} = m.\vec{a}_G$$

## الثالث — مبدأ الفعلين المتبادلين

$$\vec{F}_{A/B} = -\vec{F}_{B/A}$$

## المراجع العطالية الصالحة

سطحي أرضي (للحركات عبر سطح الأرض)، جيومركزي (الأقمار الصناعية والقمر)، هيليومركزي (الكواكب).
