# التفاعل المحدود مقابل التفاعل التام

## المعيار بثابت التوازن K ونسبة التقدم النهائي

| | **التام** | **المحدود (غير تام)** |
|---|---|---|
| نسبة التقدم | $\tau_f = 1$ | $\tau_f < 1$ |
| ثابت التوازن | $K \geq 10^4$ | $K \leq 10^{-4}$ |
| التقدم | $x_f = x_{max}$ | $x_f \neq x_{max}$ |
| حمض مع الماء | $C = [H_3O^+]$ | $C \neq [H_3O^+]$ |
| أساس مع الماء | $C = [OH^-]$ | $C \neq [OH^-]$ |

## سياق الحموضة

- الحمض القوي يتشرد كليًا (تفاعل تام مع الماء).
- الحمض الضعيف يتشرد جزئيًا (تفاعل محدود مع الماء، توازن).
