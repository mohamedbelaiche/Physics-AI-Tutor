# ثابت الزمن τ لثنائي القطب RL

## التعريف

المقدار $\frac{L}{R + r}$ متجانس مع الزمن:

$$\left[\frac{L}{R+r}\right] = [T] \qquad \tau = \frac{L}{R + r}$$

وحدة τ: الثانية.

## التعيين البياني

نفس الطرق المستعملة في ثنائي القطب RC (طريقة x%، المماس عند t=0، حوالي 5τ للنظام الدائم).
