# حل بكالوريا 2017 – شعبة تقني رياضي

**1 – معادلة التفكك:**
```
²³⁸₉₄Pu → ²³⁴₉₂U + ⁴₂He (α)
```
**2 – المعادلة التفاضلية:**
```
dNₐ/dt = λ·N(t) - 0 = λ·N₀·e^(-λt)
و Nₐ = N₀ - N = N₀ - N₀·e^(-λt)
dNₐ/dt = λ·N₀·e^(-λt) = λ·(N₀ - Nₐ) + 0
∴ dNₐ/dt + λ·Nₐ = λ·N₀  ✓
```
**3 – ثوابت الحل:**
```
Nₐ(t) = A·e^(-αt) + B
dNₐ/dt = -αA·e^(-αt)
بالتعويض: -αA·e^(-αt) + λ(A·e^(-αt) + B) = λ·N₀
(-α+λ)A·e^(-αt) + λB = λ·N₀
∴ α = λ  ,  B = N₀  ,  A = -N₀  (من شرط Nₐ(0) = 0)
```
المدلول: α = λ (ثابت التفكك)، B = N₀ (عدد الأنوية الابتدائية)
**4 –**
**أ)** `dNₐ/dt = -λ·Nₐ + λ·N₀` ← خط مستقيم
من البيان: `λ = -ميل الخط` و `N₀ = نقطة التقاطع مع المحور`
```
من الشكل-19: λ ≈ 2,5×10⁻¹⁰ s⁻¹  ,  N₀ ≈ 6×10²⁰ noyaux
```
**ب)** `t½ = ln2/λ = 0,693/(2,5×10⁻¹⁰) ≈ 87,5 ans`
**5 –**
**أ)** الطاقة المحررة من تفكك نواة واحدة:
```
Δm = m(Pu) - m(U) - m(He) = 238,04768 - 234,04095 - 4,00150 = 0,00523 u
E₀ = 0,00523 × 931,5 = 4,87 MeV = 7,8×10⁻¹³ J
```
الطاقة الكلية للكتلة m:
```
Eₜ = N·E₀ = (m/M)·Nₐ·E₀ = (1,2×10³/238)·6,02×10²³·7,8×10⁻¹³ ≈ 2,36×10¹² J
```
**ب)** مدة الاشتغال:
```
Pₜ = Pₑ/r = 888/0,6 = 1480 W
Δt = Eₜ/Pₜ = 2,36×10¹²/1480 ≈ 1,6×10⁹ s ≈ 50,7 ans
```
