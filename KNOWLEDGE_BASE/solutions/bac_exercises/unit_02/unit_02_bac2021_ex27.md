# حل بكالوريا 2021 – شعبة تقني رياضي

**1.** شرح الجملة: نشاط اليود 131 في بعض السبانخ وصل إلى 20000 Bq/kg وهو أعلى بـ10 مرات من الحد المسموح (2000 Bq/kg).
**1.2.** معادلة التفكك:
```
¹³¹₅₃I → ¹³¹₅₄Xe + ⁰₋₁e
A = 131, Z = 54
```
**2.2.** من البيان (منحنى ln(N/N₀)):
```
ميل الخط = -λ = -0,0866 j⁻¹
t½ = ln2/0,0866 ≈ 8 jours
```
**1.3.** حساب N₀ (نشاط 8 Bq لـ 1g → نشاط 8000 Bq لـ 1kg):
```
A = λ·N₀  →  N₀ = A/λ = 8000/(0,0866/(24×3600)) = 7,98×10⁹ noyaux/kg
```
**2.3.** أصغر مدة:
```
A(t) ≤ 2000 Bq/kg  →  8000·e^(-λt) ≤ 2000
e^(-λt) ≤ 0,25  →  t ≥ 2t½ = 16 jours
```
