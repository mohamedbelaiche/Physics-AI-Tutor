# حل بكالوريا 2016 – شعبة تقني رياضي

**1 – التعريفات:**
- **النظائر**: أنوية لها نفس العدد الشحني Z وتختلف في عدد الكتلة A (عدد النيوترونات)
- **النواة المشعة**: نواة غير مستقرة تتفكك تلقائياً مع إصدار إشعاعات
- **جسيمات β⁻**: إلكترونات `⁰₋₁e` ناتجة عن تحول نيوترون إلى بروتون
**2 – إيجاد x و y:**
```
انحفاظ الكتلة: 238 + x×1 = 241 + 0  →  x = 3
انحفاظ الشحنة: 92 + 0 = 94 + y×(-1)  →  y = 2
```
**3 – معادلة تفكك البلوتونيوم 241:**
```
²⁴¹₉₄Pu → ²⁴¹₉₅Am + ⁰₋₁e (β⁻)
A = 241, Z = 95
```

**أ)** `A₀/A(t) = e^(λt)  →  عبارة النسبة = e^(λt)`
**ب)** من البيان (الشكل-18): عند `A₀/A = 2`، `t = t½`:
```
من البيان: t½ ≈ 14 ans  →  λ = ln2/14 ≈ 0,05 ans⁻¹ = 1,57×10⁻⁹ s⁻¹
```
