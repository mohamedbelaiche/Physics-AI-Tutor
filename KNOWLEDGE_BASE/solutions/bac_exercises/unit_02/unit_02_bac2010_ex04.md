# حل بكالوريا 2010 – شعبة تقني رياضي

**1 – أ) معادلة التفكك:**
```
¹³⁷₅₅Cs → ¹³⁷₅₆Ba + ⁰₋₁e (β⁻)
```
**ب) حساب λ:**
```
λ = ln2/t½ = 0,693/30,2 = 2,3×10⁻² ans⁻¹ = 7,28×10⁻¹⁰ s⁻¹
```
**ج) حساب m₀:**
```
A₀ = λ·N₀ = λ·(m₀/M)·Nₐ
m₀ = A₀·M/(λ·Nₐ) = (3×10⁵×136,9)/(7,28×10⁻¹⁰×6,02×10²³)
m₀ ≈ 9,4×10⁻¹⁷ g
```
**2 – أ) قانون النشاط:**
```
A(t) = A₀·e^(-λt) = 3×10⁵·e^(-2,3×10⁻²t)   [t en ans]
```
**ب) النشاط بعد سنة:**
```
A(1an) = 3×10⁵·e^(-2,3×10⁻²) ≈ 2,93×10⁵ Bq
```
**ج) التغير النسبي:**
```
ΔA/A₀ = |A₀-A(1)|/A₀ = (1-e^(-λ)) ≈ 0,023 = 2,3%
```
**3 – مدة استغلال المنبع:**
```
A(t) = A₀/10  →  e^(-λt) = 0,1
t = ln10/λ = ln10/2,3×10⁻² ≈ 100 ans
```
