# حل بكالوريا 2024 – شعبة علوم تجريبية

**1.** النواة المشعة: نواة غير مستقرة تتفكك تلقائياً.
**2.** تركيب ⁶²₃₀Zn: 30 بروتون، 32 نيوترون
**1.3.** الجسيم β⁺ هو البوزيترون `⁰₊₁e`، يُصدر عندما يتحول بروتون إلى نيوترون داخل النواة: `p → n + e⁺ + ν`
**2.3.** معادلتا التفكك:
```
⁶²₃₀Zn → ⁶²₂₉Cu + ⁰₊₁e (β⁺)  →  A=62, Z=29
⁶²₂₉Cu → ⁶²₂₈Ni + ⁰₊₁e (β⁺)  →  A=62, Z=28
```
**ثانياً:**
**2.** طاقة ربط ⁶²₃₀Zn:
```
Eₗ = [30×1,0073 + 32×1,0087 - 61,9179] × 931,5
= [30,219 + 32,2784 - 61,9179] × 931,5
= 0,5795 × 931,5 ≈ 539,8 MeV
Eₗ/A = 539,8/62 ≈ 8,70 MeV/nuc
```
**3.** مقارنة:
```
Eₗ/A(⁶²₃₀Zn) = 8,70 MeV/nuc
Eₗ/A(⁶²₂₉Cu) = 8,74 MeV/nuc
```
**⁶²₂₉Cu** أكثر استقراراً
**ثالثاً:**
**1.** يُفضَّل لقصر نصف عمره (9,186h) مما يقلل الضرر على الجسم.
**2.** `A(t) = A₀·e^(-λt)`
**3.**
```
λ = ln2/t½ = ln2/(9,186×3600) = 2,094×10⁻⁵ s⁻¹
N₀ = (m₀/M)·Nₐ = (10×10⁻⁶/62)×6,02×10²³ ≈ 9,7×10¹⁶ noyaux
A₀ = λ·N₀ = 2,094×10⁻⁵ × 9,7×10¹⁶ ≈ 2,03×10¹² Bq
A(t₁) = 0,6·A₀  →  e^(-λt₁) = 0,6
t₁ = ln(1/0,6)/λ = 0,511/(2,094×10⁻⁵) ≈ 24400 s ≈ 6,8 h
```
