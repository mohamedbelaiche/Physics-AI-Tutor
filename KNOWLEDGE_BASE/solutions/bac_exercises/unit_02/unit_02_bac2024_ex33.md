# حل بكالوريا 2024 – شعبة تقني رياضي

**1.1.** النشاط الإشعاعي: ظاهرة تتفكك فيها الأنوية المشعة تلقائياً مع إصدار إشعاعات.
**2.1.** معادلة تفكك الثاليوم 201:
```
²⁰¹₈₁Tl → ²⁰¹₈₀Hg + ⁰₊₁e + γ
```
**1.2.** حساب A(t) لحظة الاستعمال:
الوقت المنقضي من الاستلام للاستعمال = 24 ساعة
```
λ = ln2/t½ = ln2/73 ≈ 9,49×10⁻³ h⁻¹
A(24h) = A₀·e^(-λ×24) = 153,9×10⁶ × e^(-9,49×10⁻³×24)
A(24h) = 153,9×10⁶ × e^(-0,2277) ≈ 153,9×10⁶ × 0,796 ≈ 122,5×10⁶ Bq
```
إذن `A(t) = 122,5×10⁶ Bq > 11×10⁷ Bq` → الحقنة كافية ✓
**2.3.** المدة اللازمة لعدم صلاحية القارورة:
```
A(²⁰²Tl)/A(²⁰¹Tl) < 0,02
0,005·e^(λ₂₀₂-λ₂₀₁)t < 0,02
e^(1,982×10⁻⁶t) < 4  (بالثواني)
t < ln4/(1,982×10⁻⁶) ≈ 699442 s ≈ 194,3 h
```
