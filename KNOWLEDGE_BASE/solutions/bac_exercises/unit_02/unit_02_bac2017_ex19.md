# حل بكالوريا 2017 – شعبة علوم تجريبية – دورة استدراكية

**1 – أ) التعريفات:**
- **النواة المشعة**: نواة غير مستقرة تتفكك تلقائياً مع إصدار إشعاعات
- **النظائر**: أنوية لها نفس العدد الشحني Z وتختلف في عدد النيوترونات (A مختلف)
- **العائلة المشعة**: سلسلة من التفككات المتتالية بدءاً من نواة مشعة وصولاً إلى نظير مستقر
**ب)** إيجاد x و y:
```
انحفاظ الكتلة: 238 = 206 + 4x + 0  →  x = 8
انحفاظ الشحنة: 92 = 82 + 2×8 - y  →  y = 6
```
