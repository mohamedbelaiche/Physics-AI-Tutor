# حل بكالوريا 2019 – شعبة علوم تجريبية

**1 –** أنواع التفككات:
- **α**: تصدر نواة ⁴₂He
- **β⁻**: تصدر إلكتروناً ⁰₋₁e
- **β⁺**: تصدر بوزيتروناً ⁰₊₁e
- **التقاط إلكتروني**: التقاط بروتون لإلكترون
**2 –**
1.2. من المخطط: `N = 17, Z = 16` → `A = N+Z = 33` → رمز النواة الموافقة: **¹⁶³³S**
2.2. معادلة التفكك:
```
¹⁵³²P → ¹⁶³²S + ⁰₋₁e (β⁻)
```
**3 –**
1.3. `N₀ = n₀·Nₐ = 3,12×10⁻¹⁰ × 6,02×10²³ ≈ 1,88×10¹⁴ noyaux`
2.3. 99% متفككة → 1% متبقية:
```
N = 0,01·N₀  →  e^(-λt) = 0,01
t = ln100/λ = ln100/(ln2/14,32) = 14,32×ln100/ln2 ≈ 95 jours  ✓
```
**4 –**
1.4. 
```
Eₗ(³²P) = [15×1,00728 + 17×1,00866 - 31,97391] × 931,5 ≈ 263,2 MeV
Eₗ(³⁰P) = [15×1,00728 + 15×1,00866 - 29,97831] × 931,5 ≈ 242,9 MeV
```
