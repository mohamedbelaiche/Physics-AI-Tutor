# حل بكالوريا 2014 – شعبة تقني رياضي

**1 – معادلة التفكك:**
```
²¹⁰₈₃Bi → ²¹⁰₈₄Po + ⁰₋₁e + γ
```
مصدر الإلكترون: تحول نيوترون إلى بروتون داخل النواة: `¹₀n → ¹₁p + ⁰₋₁e + ν̄`
**2 – عدد الأنوية المتفككة:**
```
Nₐ(t) = N₀ - N(t) = N₀ - N₀·e^(-λt) = N₀(1 - e^(-λt))
```
**3 – أ) النشاط الإشعاعي:**
النشاط الإشعاعي A هو عدد التفككات الحادثة في الثانية الواحدة. وحدته: **البيكريل (Bq)**.
**ب) عبارة ln A(t):**
```
A(t) = λ·N(t) = λ·N₀·e^(-λt)
ln A(t) = ln(λ·N₀) - λt = lnA₀ - λt
```
**ج) من المنحنى (الشكل-8):**
```
a = Δ(lnA)/Δt = -λ  →  من الشكل: λ ≈ 0,1388 j⁻¹
lnA₀ = b (قيمة المحور عند t = 0) = 25  →  A₀ = e²⁵ ≈ 7,20×10¹⁰ Bq
```
