# حل بكالوريا 2022 – شعبة تقني رياضي

**1.1.** النواة المشعة: نواة غير مستقرة تتفكك تلقائياً مع إصدار إشعاعات.
**2.1.** القوة النووية القوية: قوة جاذبة قصيرة المدى تربط النيوكليونات (نيوترونات وبروتونات) ببعضها.
**3.1.** أنماط الإشعاعات:
- α: `⁴₂He`
- β⁻: `⁰₋₁e`  
- β⁺: `⁰₊₁e`
- γ: `⁰₀γ`
**1.2.** تعرف الأنوية:
```
X₁ → ²¹²₈₂Pb  ,  X₂ → ²¹²₈₃Bi  ,  X₃ → ²⁰⁸₈₁Tl  ,  X₄ → ²⁰⁸₈₂Pb
```
**2.2.** X₁ و X₂ **نظيران** لأن لهما نفس Z = 82 (رصاص)؟ لا ليسا نظيرين لأن X₂ هو Bi (Z=83).
**3.2.** المعادلات:
```
① ²¹²₈₃Bi → ²¹²₈₄Po + ⁰₋₁e (β⁻)
② ²¹²₈₃Bi → ²⁰⁸₈₁Tl + ⁴₂He (α)
③ ²⁰⁸₈₁Tl → ²⁰⁸₈₂Pb + ⁰₋₁e (β⁻)
```
**1.3.** `N(t) = N₀·e^(-λt)`
**1.2.3.** إثبات:
```
Nₜₗ(t) = N₀ - N(t) = N₀ - N₀·e^(-λt) = N₀(1-e^(-λt))  ✓
```
**2.2.3.** من البيان (الشكل-4):
```
t½ = 60 min (عند Nₜₗ = N₀/2)
N₀ = 28×10²⁰ noyaux  ,  m₀ = (N₀/Nₐ)·M = (28×10²⁰/6,02×10²³)×212 ≈ 1 g
A₀ = λ·N₀ = (ln2/3600)×28×10²⁰ ≈ 5,4×10¹⁷ Bq
```
