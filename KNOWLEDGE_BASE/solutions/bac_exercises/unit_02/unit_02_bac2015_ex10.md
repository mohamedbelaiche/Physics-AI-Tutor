# حل بكالوريا 2015 – شعبة علوم تجريبية

**1 – تركيب نواة اليود ¹³¹₅₃I:**
- بروتونات: Z = 53
- نيوترونات: N = 131 - 53 = 78
**2 – أ)** الجسيم المنبعث: **β⁻** (إلكترون)
**ب) معادلة التفكك:**
```
¹³¹₅₃I → ¹³¹₅₄Xe + ⁰₋₁e
```
قوانين الانحفاظ: انحفاظ العدد الكتلي (131 = 131 + 0) وانحفاظ العدد الشحني (53 = 54 - 1) ✓
**3 – عبارة ln(A):**
```
A(t) = A₀·e^(-λt)  →  lnA = lnA₀ - λt = -λt + lnA₀
lnA = -(ln2/t½)·t + lnA₀
```
**4 – من البيان (الشكل-14):**
ميل المستقيم `a = -ln2/t½`، عند `t = 0`: `lnA₀ = 14,4`
```
A₀ = e^14,4 ≈ 4,3×10⁶ Bq
ميل المستقيم ≈ -0,09 j⁻¹  →  λ = 0,09 j⁻¹
t½ = ln2/0,09 ≈ 8 jours
```
**5 – الكتلة الابتدائية:**
```
m₀ = A₀·t½·M/(ln2·Nₐ) = (4,3×10⁶×8×24×3600×131)/(0,693×6,02×10²³)
m₀ ≈ 0,9 g
```
