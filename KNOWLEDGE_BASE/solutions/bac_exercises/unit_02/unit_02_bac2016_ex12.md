# حل بكالوريا 2016 – شعبة تقني رياضي

**1 – أ) معادلة التفكك:**
```
¹⁵³²P → ¹⁶³²S + ⁰₋₁e (β⁻)
```
**ب) قانون التناقص:**
```
N(t) = N₀·e^(-λt)  →  m(t) = m₀·e^(-λt)
```
**ج) التحقق من طاقة الربط:**
```
Eₗ/A = [Z·mₚ + (A-Z)·mₙ - m(³²P)] × 931,5 / A
= [15×1,00728 + 17×1,00866 - 31,9657] × 931,5 / 32
= 8,46 MeV/nucléon  ✓
```
**2 – إثبات m'(t):**
```
m'(t) = m₀ - m(t) = m₀ - m₀·e^(-λt) = m₀(1 - e^(-λt))  ✓
```
**3 –** النواة الأخرى في المخطط (N-Z) هي **³²S** (الكبريت). معادلة التحول:
```
³²S → ³²P + ... (التقاط إلكتروني أو β⁺)
```
**4 – إثبات t = 2t½:**
```
A(t)/A₀ = 1/4 = e^(-λt)  →  λt = ln4 = 2ln2  →  t = 2ln2/λ = 2t½  ✓
```
