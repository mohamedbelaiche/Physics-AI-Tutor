# حل بكالوريا 2024 – شعبة تقني رياضي

**1 –**
**1.1.1.** الانشطار النووي: تفاعل نووي يتم فيه قذف نواة ثقيلة بنيوترون فتنقسم إلى نواتين أخف مع تحرير نيوترونات وطاقة كبيرة.
**2.1.1.** التفاعل (1) ليس انشطاراً نووياً لأن الناتج نواة واحدة (²³³₉₀Th) وليس نواتين.
**3.1.1.** `²³²₉₀Th + ¹₀n → ²³³₉₀Th`
**2.1.** حساب الطاقة المحررة من انشطار ²³³₉₂U:
```
Δm = m(²³³U) + m(n) - m(¹³⁷Xe) - m(⁹⁴Sr) - 3m(n)
= 233,03963 + 1,00866 - 136,91156 - 93,91536 - 3×1,00866
= 0,19539 u
E = 0,19539 × 931,5 ≈ 182 MeV
```
**1.2.** معادلة تفكك اليورانيوم 234:
```
²³⁴₉₂U → ²³⁰₉₀Th + ⁴₂He (α)
```
**3.2.2.** حساب عمر الصخرة:
```
N(Th)/N(U) = e^(λt) - 1 = 3/4
e^(λt) = 7/4 = 1,75
t = ln(1,75)/λ = ln(1,75)/(ln2/t½) = t½/ln2 × ln(1,75)
= (2,455×10⁵/0,693) × 0,5596 ≈ 1,98×10⁵ ans
```
