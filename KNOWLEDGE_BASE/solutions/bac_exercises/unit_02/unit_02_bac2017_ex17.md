# حل بكالوريا 2017 – شعبة تقني رياضي

**1 –**
النشاط الإشعاعي β⁻: ظاهرة نووية تلقائية يتحول فيها نيوترون إلى بروتون مع انبعاث إلكترون.
```
⁶⁰₂₇Co → ⁶⁰₂₈Ni* + ⁰₋₁e + γ
```
**2 –**
**أ)** `N₀ = (m₀/M)·Nₐ = (2×10⁻⁶/60)×6,02×10²³ = 2×10¹⁶ noyaux`
**ب)** `N(t) = N₀·e^(-λt)`
**ج)** إثبات: `A(t) = λ·N(t) = λ·N₀·e^(-λt) = A₀·e^(-λt)`
```
A(t)/A₀ = e^(-λt) = N(t)/N₀ = m(t)/m₀  ✓
```
**3 –**
**أ)** `t½ ≈ 5,3 ans` (من البيان عند `A/A₀ = 0,5`)
**ب)** `λ = ln2/t½ = ln2/5,3 ≈ 0,13 an⁻¹` ✓ (يوافق القيمة المعطاة)
**ج)** `A(t) = A₀·e^(-λt)` حيث `A₀ = λ·N₀ = 0,13/(365×24×3600)×2×10¹⁶ ≈ 8,2×10⁷ Bq`
