# حل بكالوريا 2023 – شعبة تقني رياضي

**1.** النواة المشعة: نواة غير مستقرة تتفكك تلقائياً.
خصائص النشاط الإشعاعي: تلقائي، عشوائي، حثي.
**1.2.** إيجاد A و Z:
```
¹³⁷₅₅Cs → ⁴₂X + ⁰₋₁e
انحفاظ الكتلة: 137 = A + 0  →  A = 137
انحفاظ الشحنة: 55 = Z - 1  →  Z = 56
```
النواة الناتجة: **¹³⁷₅₆Ba**
**2.2.** نمط التفكك: **β⁻** — يتحول نيوترون إلى بروتون داخل النواة مع انبعاث إلكترون.
**1.3.** من البيان: `t½ = 30,2 ans`
**2.3.** `A(t) = A₀·e^(-λt)` حيث `λ = ln2/t½`
**3.3.** حساب m₀:
```
A₀ = λ·N₀ = λ·(m₀/M)·Nₐ
من البيان عند t=0: A₀ ≈ 10¹⁰ Bq (من الشكل-2 عند t=0 قبل 0,6)
λ = ln2/30,2 = 0,693/30,2 ≈ 0,023 ans⁻¹ = 7,28×10⁻¹⁰ s⁻¹
m₀ = A₀·M/(λ·Nₐ) = (10¹⁰×137)/(7,28×10⁻¹⁰×6,02×10²³) ≈ 3,13×10⁻⁹ g
```
**4.** 99% من الأنوية تتفكك:
```
N = 0,01·N₀  →  t = ln100/λ = 100·ln2/λ·(1/ln100)... 
t = t½/ln2 × ln100 = 30,2/0,693 × 4,605 ≈ 200,5 ans
```
**5.** بعد مرور 37 سنة من 1986:
```
A(37)/A₀ = e^(-0,023×37) = e^(-0,851) ≈ 0,427 = 42,7%
```
المنطقة **لا تزال خطرة** لأن 42,7% من النشاط لا يزال موجوداً.
