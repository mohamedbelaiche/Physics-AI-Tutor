# حل بكالوريا 2018 – شعبة علوم تجريبية

**1 –** تركيب ¹³¹₅₃I: 53 بروتون، 78 نيوترون
**2 –**
```
N₀ = m₀/m(noyau) = 1×10⁻⁶/(2,176×10⁻²⁵) ≈ 4,6×10¹⁸ noyaux
```
**3 –**
1.3. يصدر الإلكترون لأن نيوترون يتحول إلى بروتون داخل النواة.
2.3. معادلة التفكك:
```
¹³¹₅₃I → ¹³¹₅₄Xe + ⁰₋₁e
```
3.3. `N(t) = N₀·e^(-λt)`
4.3. `t½ = ln2/λ  →  λ = ln2/t½ = 0,693/8 = 0,0866 j⁻¹`
5.3. 
```
A₀ = λ·N₀ = (0,0866/(24×3600))×4,6×10¹⁸ ≈ 4,6×10¹² Bq
```
**4 –**
```
A(t) = 0,4·A₀  →  e^(-λt) = 0,4  →  t = ln(1/0,4)/λ = ln(2,5)/0,0866 ≈ 10,57 jours
```
المريض يخرج بعد ≈ **10 أيام و 14 ساعة** من تاريخ الحقن (أي يوم 21 ماي 2018 على الساعة العاشرة صباحاً).
