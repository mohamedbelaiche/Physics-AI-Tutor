# حل بكالوريا 2015 – شعبة تقني رياضي

**1 – أ) معادلة التحول:**
```
A: 186 = 186 + 0 → A = 186 - 186 = 0 → نمط β
Z: 75 = 76 + Z → Z = -1
∴ ¹⁸⁶₇₅Re → ¹⁸⁶₇₆Os + ⁰₋₁e (β⁻)
```
**ب)** نمط التحول: **β⁻** — يتحول نيوترون إلى بروتون داخل النواة مع انبعاث إلكترون وضد نيوترينو.
**2 – من البيان:**
**أ)** `A₀ = 4×10⁹ Bq`
**ب)** `t½ = 3,5 jours` (من البيان)
**ج)** `λ = ln2/t½ = 0,693/3,5 ≈ 0,198 j⁻¹ = 2,3×10⁻⁶ s⁻¹`
**3 – عدد الأنوية عند t₁ = 10 jours:**
```
N(t₁) = (A₀/λ)·e^(-λt₁) = (4×10⁹/2,3×10⁻⁶)·e^(-0,198×10)
N(10j) ≈ 2,4×10¹⁴ noyaux
```
**4 – حجم الحقنة V:**
```
N(t₁)/V₀ = 1,2×10¹⁴/V  →  V = 1,2×10¹⁴·V₀/N(t₁)
V = (1,2×10¹⁴ × 10×10⁻³)/2,4×10¹⁴ = 5×10⁻³ L = 5 mL
```
