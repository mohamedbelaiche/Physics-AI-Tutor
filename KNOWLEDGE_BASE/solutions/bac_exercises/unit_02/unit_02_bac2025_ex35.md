# حل بكالوريا 2025 – شعبة علوم تجريبية

**أوّلا:**
**1.** معادلة التفكك:
```
¹⁵³₆₂Sm → ¹⁵³₆₃Eu + ⁰₋₁e (β⁻)
A = 153, Z = 63
```
**1.2.** سبب الاستعمال: نصف عمره قصير (46,28h) فيختفي بسرعة ويقلل الضرر الإشعاعي.
**2.2.** `N₀ = (m₀/M)·Nₐ = (100×10⁻⁶/153)×6,02×10²³ ≈ 3,93×10¹⁷ noyaux`
**3.2.** إثبات:
```
A(t) = |dN/dt| = λN₀e^(-λt) = A₀e^(-λt)  ✓
```
**4.2.** حساب t:
```
A(t) = A₀/4  →  e^(-λt) = 1/4  →  t = 2ln2/λ = 2t½ = 2×46,28 = 92,56 h
```
**ثانيا:**
**1.** تفاعل انشطار نووي: تفاعل تنقسم فيه نواة اليورانيوم بعد قذفها بنيوترون إلى نواتين وعدة نيوترونات مع تحرير طاقة كبيرة.
**2.** الأسباب الفيزيائية: نواة اليورانيوم مستقطبة كهربائياً وتحتاج نيوترون (لا شحنة له) لاختراق الحاجز الكولومبي.
**3.** الطاقة المحررة من نواة ²³⁵U واحدة:
```
Δm = m(²³⁵U) + m(n) - m(¹⁵³Sm) - m(⁸⁰Zn) - 3m(n)
= 234,99333 + 1,00866 - 152,92210 - 79,94434 - 3×1,00866
= 0,16957 u
E = 0,16957 × 931,5 ≈ 158 MeV = 2,53×10⁻¹¹ J
```
المصدر: عجز الكتلة (تحول كتلة إلى طاقة وفق E = Δmc²)
**4.** الطاقة لتحضير الجرعة:
```
N₀ = 3,93×10¹⁷ نواة سماريوم → نفس عدد نوى اليورانيوم المنشطرة
Eₜ = N₀ × E = 3,93×10¹⁷ × 2,53×10⁻¹¹ ≈ 9,9×10⁶ J = 62,5 MeV (تقريبياً للنواة الواحدة)
```
