# حل بكالوريا 2008 – شعبة علوم تجريبية

**1 – أ) المقصود بالعبارة:**
- **تصدر جسيمات β⁻**: أي تصدر إلكترونات سريعة ناتجة عن تحول نيوترون إلى بروتون داخل النواة
- **وإشعاعات γ**: أشعة كهرومغناطيسية قصيرة الموجة تصدر عندما تنتقل النواة من حالة إثارة إلى حالة أكثر استقراراً
**ب) معادلة التفكك:**
```
¹³⁷₅₅Cs → ¹³⁷₅₆Ba + ⁰₋₁e + γ
```
النواة الابن هي: **¹³⁷₅₆Ba**
**2 – أ) حساب N₀:**
```
N₀ = (m/M)·Nₐ = (1,0×10⁻⁶/137) × 6,023×10²³
N₀ ≈ 4,4×10¹⁵ noyaux
```
**ب) النشاط الإشعاعي:**
```
λ = ln2/τ = 0,693/(43,3×365×24×3600) = 7,4×10⁻¹⁰ s⁻¹
A₀ = λ·N₀ = 7,4×10⁻¹⁰ × 4,4×10¹⁵ ≈ 3,2×10⁶ Bq
```
**3 – أ) النشاط بعد 6 أشهر:**
```
t = 6 mois = 0,5 an
A(6mois) = A₀·e^(-λt) = 3,2×10⁶·e^(-0,693×0,5/43,3)
A ≈ 3,16×10⁶ Bq
```
**ب) النسبة المئوية للأنوية المتفككة:**
```
N' = N₀ - N = N₀(1 - e^(-λt))
N'/N₀ = 1 - e^(-λt) ≈ 0,011 = 1,1%
```
**4 – المدة اللازمة لانعدام النشاط:**
```
A = 0,01·A₀  →  e^(-λt) = 0,01  →  t = ln100/λ = 5τ
t = 5 × 43,3 = 216,5 ans
```
يمكن تعميم هذه النتيجة على أي نواة مشعة: **t = 5τ**
