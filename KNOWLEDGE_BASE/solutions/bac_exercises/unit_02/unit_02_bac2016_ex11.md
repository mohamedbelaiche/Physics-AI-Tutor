# حل بكالوريا 2016 – شعبة علوم تجريبية

**1 – أ) معادلة التفكك:**
```
¹⁰₄Be → ¹⁰₅B + ⁰₋₁e
A = 10, Z = 5  →  النواة البنت: ⁵B (البورون)
```
**ب)** ينبعث إلكترون β⁻ لأن نيوترون يتحول إلى بروتون داخل النواة: `n → p + e⁻ + ν̄`
**2 – أ) قانون التناقص:**
```
N(t) = N₀·e^(-λt)
```
**ب) كتلة البيريليوم المتبقية:**
```
m(t) = (M·N(t)/Nₐ) = (M·N₀/Nₐ)·e^(-λt) = m₀·e^(-λt)
```
**3 – أ)** `t½ = ln2/λ`
**ب) من البيان (الشكل-16):**
عند `m = m₀/2 = 0,5/2 = 0,25 g`: `t½ ≈ 0,5×10⁶ ans` (نقرأ بيانياً)
```
λ = ln2/t½ = 0,693/(0,5×10⁶×365,25×24×3600) ≈ 4,37×10⁻¹⁴ s⁻¹
```
**ج)** عدد الأنوية المتفككة عند `t = 1 année`:
```
N' = N₀(1 - e^(-λ×1an)) = (m₀/M)·Nₐ·(1 - e^(-λ×365,25×24×3600))
```
**4 –**
```
N₀ = (m/M)·Nₐ = (3/10)×6,023×10²³ = 1,8×10²² noyaux
λ = A/N₀ = 1,06×10¹⁵/1,8×10²² = 5,9×10⁻⁸ s⁻¹
```
**ب)** عمر العينة:
```
e^(-λt) = m/m₀ = 3/4000  →  t = ln(4000/3)/λ ≈ 1,7 ans
```
