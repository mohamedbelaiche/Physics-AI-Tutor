# حل بكالوريا 2016 – شعبة علوم تجريبية – دورة استدراكية

**1 – أ) خصائص النشاط الإشعاعي:**
تلقائي، عشوائي، حثي، لا يتأثر بالعوامل الخارجية (الضغط، الحرارة...)
**ب) معادلة التفكك:**
```
⁴⁰₁₉K → ⁴⁰₂₀Ca + ⁰₋₁e (β⁻)
```
**2 –**
**أ)** المنحنى (2) يمثل تغيرات عدد أنوية الكالسيوم لأنه يبدأ من الصفر ويتزايد.
**ب)** نقطة التقاطع تمثل اللحظة التي يصبح فيها عدد أنوية K مساوياً لعدد أنوية Ca، وهو اللحظة التي يتساوى فيها N(K) = N₀/2، أي: **t = t½**
من البيان: `t½ ≈ 1,3×10⁹ ans`
**ج)** النشاط الابتدائي:
```
A₀ = λ·N₀ = (ln2/t½)·N₀
```
من البيان: `N₀ = 2×10²²`
```
A₀ = (0,693/(1,3×10⁹×365,25×24×3600)) × 2×10²² ≈ 3,4×10⁵ Bq
```
**3 –** من البيان: `t₁ ≈ 2×10⁹ ans`
تحقق حسابي: `N(K) = N₀/4Ca` عندما `N(K) = N₀/4`:
```
e^(-λt₁) = 1/4  →  t₁ = 2t½ ≈ 2,6×10⁹ ans
```
