# حل بكالوريا 2014 – شعبة علوم تجريبية

**1 – التعريفات:**
- **النظير المشع**: نواة غير مستقرة تتفكك تلقائياً مع إصدار إشعاعات (α أو β أو γ)
- **الإشعاع β⁻**: جسيم إلكترون `⁰₋₁e` منبعث من النواة نتيجة تحول نيوترون إلى بروتون
**2 – معادلة النشاط:**
```
¹³⁴₅₅Cs → ¹³⁴₅₆Ba + ⁰₋₁e + γ
```
**3 – من المنحنى (الشكل-11):**
**أ)** `A₀ = 25×10¹⁰ Bq` (عند t = 0)
**ب)** عند `t = τ`: `A(τ) = A₀/e ≈ A₀×0,37`  
من البيان: `A(τ) ≈ 9,2×10¹⁰ Bq` → `τ ≈ 2,85 ans`
**ج)** `t½ = τ·ln2 = 2,85 × 0,693 ≈ 1,98 ans`
**د)** حساب m₀:
```
A₀ = λ·N₀ = (ln2/t½)·(m₀/M)·Nₐ
m₀ = A₀·t½·M/(ln2·Nₐ) = (25×10¹⁰×1,98×365×24×3600×134)/(0,693×6,02×10²³)
m₀ ≈ 1 mg
```
