# حل بكالوريا 2025 – شعبة تقني رياضي

**1.** نظائر عنصر كيميائي: أنوية لها نفس العدد الشحني Z وتختلف في العدد الكتلي A (عدد النيوترونات مختلف).
**2.** إيجاد A₁ و Z₂:
```
انحفاظ الكتلة: 235 + 1 = A₁ + 140 + 2  →  A₁ = 94
انحفاظ الشحنة: 92 + 0 = 38 + Z₂ + 0  →  Z₂ = 54
```
إذن: **⁹⁴₃₈Sr** و **¹⁴⁰₅₄Xe** ✓
**3.** طاقة ربط ⁹⁴₃₈Sr:
```
Eₗ/A(⁹⁴Sr) = 8,1 MeV/nucl (من معطيات Xe)
الواقع: من معطيات m(⁹⁴Sr):
Eₗ = [38×1,0073 + 56×1,0087 - 93,9154] × 931,5
= [38,2774 + 56,4872 - 93,9154] × 931,5 = 0,8492 × 931,5 ≈ 791,2 MeV
Eₗ/A = 791,2/94 ≈ 8,42 MeV/nucl
```
الأكثر استقراراً: **¹⁴⁰Xe** (Eₗ/A = 8,1 × 140 / 140 = 8,1 ← لكن Sr: 8,42 > 7,6 لـ U)
ترتيب تصاعدياً: U (7,6) < Xe (8,1) < Sr (8,42) → **Sr الأكثر استقراراً**
**4.** مصدر الطاقة: عجز الكتلة (الكتلة الناتجة < الكتلة الابتدائية)
```
Δm = m(²³⁵U) + m(n) - m(⁹⁴Sr) - m(¹⁴⁰Xe) - 2m(n)
= (235×7,6 + 94×8,42 + 140×8,1 - 235×7,6) ... 
```
طريقة بطاقات الربط:
```
E_lib = Eₗ(Sr) + Eₗ(Xe) - Eₗ(U) - 0
= 94×8,42 + 140×8,1 - 235×7,6
= 791,5 + 1134 - 1786 = 139,5 MeV ≈ 2,23×10⁻¹¹ J
```
**5.** طاقة 1 kg يورانيوم 235:
```
N = (1000/235)×6,02×10²³ = 2,56×10²⁴ نواة
E_total = 2,56×10²⁴ × 2,23×10⁻¹¹ ≈ 5,71×10¹³ J
```
**6.** مقارنة:
```
E(بترول) = 42×10⁶ J/kg
E(يورانيوم) ≈ 5,71×10¹³ J/kg
النسبة = 5,71×10¹³/42×10⁶ ≈ 1,36×10⁶
```
**الاستنتاج:** طاقة 1 kg يورانيوم تعادل طاقة أكثر من **مليون مرة** من 1 kg بترول، مما يبرز الأهمية الكبرى للطاقة النووية كمصدر طاقة فعّال ومركّز.
