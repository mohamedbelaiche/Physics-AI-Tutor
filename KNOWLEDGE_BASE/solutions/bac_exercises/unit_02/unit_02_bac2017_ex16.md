# حل بكالوريا 2017 – شعبة تقني رياضي

**1 –**
- α: جسيم نواة الهيليوم `⁴₂He`
- β⁻: إلكترون `⁰₋₁e`
```
انحفاظ الكتلة: 238 = 4x + 0×y + 206  →  x = 8
انحفاظ الشحنة: 92 = 2×8 - y + 82  →  y = 6
```
**2 – إثبات علاقة الكتلة:**
```
N_U(t) = N_U(0)·e^(-λt)
N_Pb = N_U(0) - N_U(t) = N_U(0)(1 - e^(-λt))
mₚᵦ = (M_Pb/M_U)·m_U(0)·(1 - e^(-λt))
= (206/238)·m_U(0)·(1 - e^(-λt))
≈ 0,866·m_U(0)·(1 - e^(-λt))  ✓
```
**3 – من البيان (الشكل-20):**
**أ)** عند `t = 0`: `mₚᵦ = 0`، من منحنى التشبع: `0,866·m_U(0) = 2 g`
```
∴ N_U(0) = (m_U(0)/M_U)·Nₐ = (2,31/238)×6,02×10²³ ≈ 5,84×10²¹ noyaux
```
**ب)** من البيان: `t½ ≈ 4,5×10⁹ ans`
**ج)** عمر العينة:
```
tₘ = t½/ln2 × ln(m_U(0)/(m_U(0) - mₚᵦ/0,866))
mₚᵦ = 0,31 × 2,31 = 0,716 g  (31% من كتلة U الابتدائية)
```
**4 –** يورانيوم 238 لا يزال موجوداً لأن `t½ = 4,5×10⁹ ans ≈ عمر الأرض`، فلم يتفكك إلا نصفه تقريباً.
