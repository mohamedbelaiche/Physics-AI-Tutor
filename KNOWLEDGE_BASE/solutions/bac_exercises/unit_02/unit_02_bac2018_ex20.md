# حل بكالوريا 2018 – شعبة تقني رياضي

**1 – التعريفات:**
- **نظير**: نواة لها نفس العدد الشحني Z مع عدد كتلة A مختلف
- **مشع**: نواة غير مستقرة تتفكك تلقائياً
- **نشاط عينة**: عدد التفككات الحادثة في الثانية الواحدة
**2)** `A(t) = A₀·e^(-λt)`
**3)** إثبات:
```
A(t) = A₀·e^(-λt)  →  ln A = ln A₀ - λt
-ln A = λt - ln A₀ = at - ln(b)
∴ a = λ  ,  b = A₀
```
**4 – من البيان:**
```
من النقطة (t₁, y₁) = (2,11×10⁴ s, 46,93):
-lnA = 46,93  →  A(t₁) = e^(-46,93)
ميل الخط: a = Δ(-lnA)/Δt = (46,93-lnA₀)/(2,11×10⁴-0) = λ
b = A₀ = e^(lnA₀) (من التقاطع مع المحور)
```
من قراءة البيان: `a = λ ≈ 4,45×10⁻³ s⁻¹`
```
t½ = ln2/λ = 0,693/(4,45×10⁻³) ≈ 156 s ≈ 2,6 min
```
**2 – طبيعة النظير:** من الجدول، `t½ ≈ 2,6 min → P` (الفوسفور)، إذن النظير المدروس هو **¹⁵³²P**
