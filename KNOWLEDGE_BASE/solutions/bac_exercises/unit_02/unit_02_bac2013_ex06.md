# حل بكالوريا 2013 – شعبة تقني رياضي

**1 – أ) التعريفات:**
- **نواة مشعة**: نواة غير مستقرة تتفكك تلقائياً مع إصدار إشعاعات
- **النظائر**: أنوية لها نفس العدد الشحني Z وتختلف في عدد النيوترونات
**ب) معادلة الحصول على ²⁴₁₁Na:**
```
²³₁₁Na + ¹₀n → ²⁴₁₁Na
```
**2 – معادلة تفكك الصوديوم 24:**
```
²⁴₁₁Na → ²⁴₁₂Mg + ⁰₋₁e (β⁻)
```
النواة الابن: **¹²Mg**
**3 – من البيان:**
**أ)** `n₀ = 2×10⁻⁶ mol` (قراءة من البيان عند t = 0)
**ب)** `t½ = 15 h` (من البيان عند `n = n₀/2`)
**4 – أ) إثبات العلاقة:**
قانون التناقص الإشعاعي: `n(t) = n₀·e^(-λt)` ✓
**ب)** `n(6h) = n₀·e^(-λ×6) = 2×10⁻⁶·e^(-0,693×6/15) ≈ 1,58×10⁻⁶ mol`
ملاحظة: القيمة من البيان `n₁ = 7,6×10⁸ mol` (وحدات مختلفة)
**5 – حجم دم المريض:**
```
n₁/V = n₂/V₂  →  V = n₁·V₂/n₂ = (7,6×10⁸ × 10)/(1,5×10⁸) ≈ 5 L
```
