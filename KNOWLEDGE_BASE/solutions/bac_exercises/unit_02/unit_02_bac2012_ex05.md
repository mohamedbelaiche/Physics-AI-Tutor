# حل بكالوريا 2012 – شعبة علوم تجريبية

**1 – تركيب نواة اليود ¹³¹₅₃I:**
- عدد البروتونات: Z = 53
- عدد النيوترونات: N = A - Z = 131 - 53 = 78
**2 – طاقة الربط:**
```
Eₗ = [Z·mₚ + (A-Z)·mₙ - m(¹³¹I)]·c²
Eₗ = [53×1,00728 + 78×1,00866 - 130,97851] × 931,5
Eₗ = 1,1049 × 931,5 ≈ 1009 MeV
```
**3 – معادلة التفكك:**
بتطبيق قوانين الانحفاظ (β⁻):
```
¹³¹₅₃I → ¹³¹₅₄Xe + ⁰₋₁e
```
النواة الابن هي: **¹³¹₅₄Xe**
**4 – أ) قانون التناقص:**
```
N(t) = N₀·e^(-λt)
```
**ب) من المنحنى:**
ميل المستقيم: `a = Δ(lnN)/Δt = -λ`
من البيان: `λ ≈ 8,7×10⁻² jours⁻¹`
```
t½ = ln2/λ = 0,693/0,087 ≈ 7,7 jours ≈ 8,2 jours
```
**ج) الكتلة المتفككة بعد 16 jours:**
```
N(16) = N₀·e^(-0,087×16) = N₀·e^(-1,392) ≈ 0,249·N₀
الكتلة المتبقية: m(16) = m₀ × 0,249 ≈ 0,249 × 0,696 ≈ 0,173 g
الكتلة المتفككة: m' = m₀ - m(16) = 0,696 - 0,173 ≈ 0,523 g
```
