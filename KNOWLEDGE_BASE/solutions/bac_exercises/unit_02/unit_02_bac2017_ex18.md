# حل بكالوريا 2017 – شعبة علوم تجريبية

**1)** النشاط الإشعاعي التلقائي: ظاهرة تلقائية وعشوائية وحثية تتفكك فيها الأنوية المشعة غير المستقرة
**2)** أنماط التفكك في المعادلة (*):
- **α**: نواة هيليوم ⁴₂He
- **β⁻**: إلكترون ⁰₋₁e
**3)** إيجاد x و y:
```
انحفاظ الكتلة: 238 = 206 + 4x + 0  →  x = 8
انحفاظ الشحنة: 92 = 82 + 2×8 - y  →  y = 6
```
**4)** عدد أنوية اليورانيوم في العينة:
```
A = λ·N  →  N = A/λ = A·t½/ln2 = (2,35×10⁵ × 4,47×10⁹×365×24×3600)/(0,693)
N ≈ 4,78×10²² noyaux
```
**5)** نسبة اليورانيوم:
```
p = (N·M/Nₐ)/m_total × 100 = (4,78×10²²×238/(6,02×10²³))/47000 × 100
p ≈ 0,04%
```
نعم المنجم قابل للاستغلال لأن p > 0,01%
