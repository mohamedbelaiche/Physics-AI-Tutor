# حل بكالوريا 2009 – شعبة علوم تجريبية

**1 –**
- **عنصر مشع**: عنصر تتفكك أنويته تلقائياً مع إصدار إشعاعات
- **عنصر نظائر**: عناصر لها نفس العدد الذري Z وتختلف في العدد الكتلي A (عدد النيوترونات)
**2 – معادلة التفكك:**
بتطبيق قوانين الانحفاظ:
```
²¹⁰₈₄Po → ⁴₂He + ⁴₂Pb
A: 210 = 4 + A → A = 206
Z: 84 = 2 + Z → Z = 82
∴ ²¹⁰₈₄Po → ⁴₂He + ²⁰⁶₈₂Pb
```
**3 – أ) حساب λ:**
```
λ = ln2/t½ = 0,693/138 = 5×10⁻³ j⁻¹ = 5,78×10⁻⁸ s⁻¹
```
**ب) حساب N₀:**
```
A₀ = λ·N₀  →  N₀ = A₀/λ = 10⁸/(5,78×10⁻⁸)
N₀ ≈ 1,73×10¹⁵ noyaux
```
**ج) المدة الزمنية لتناقص العدد إلى الربع:**
```
N = N₀/4  →  e^(-λt) = 1/4
λt = ln4 = 2ln2  →  t = 2t½ = 2×138 = 276 jours
```
