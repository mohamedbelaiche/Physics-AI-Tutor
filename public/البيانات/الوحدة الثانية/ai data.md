# الوحدة 20: التحولات النووية (فيزياء - بكالوريا)

**المصدر:** ثانوية عين اسرار بالجلفة — الأستاذ: سابق بولرباح

---

## 1. المتطلبات السابقة (Prerequisites)

قبل دراسة هذه الوحدة، يجب أن يكون الطالب متمكنًا من:
- بنية الذرة والنواة (البروتونات، النترونات، الإلكترونات).
- رمز العنصر الكيميائي وقراءة الجدول الدوري.
- مفهوم الكتلة والطاقة الأساسي (ميكانيك كلاسيكي).
- التعامل مع الأسس واللوغاريتمات (ln) والدوال الأسية (exponentielle) رياضيًا.
- وحدات القياس العلمية (kg, J, s) وتحويلاتها.

---

## 2. المفاهيم الأساسية (Concepts)

### 2.1 رمز النواة
النواة ترمز بالشكل: **X​₂ᴬ** حيث:
- **A**: العدد الكتلي = عدد النكليونات (البروتونات + النترونات).
- **Z**: العدد الذري = عدد البروتونات.
- **N**: عدد النترونات، ويحسب بالعلاقة: **N = A − Z**

### 2.2 النظائر (Isotopes)
ذرات لها **نفس العدد الذري (Z)** وتختلف في **العدد الكتلي (A)**، وبالتالي تختلف في عدد النترونات (N).

### 2.3 أنواع الإشعاعات النووية التلقائية
معظم الأنوية غير المستقرة تتحول تلقائيًا إلى أنوية مستقرة عبر آلية **التفكك الإشعاعي**، الذي ينتج عنه:

| النوع | الوصف | الأنوية المعنية |
|---|---|---|
| **إشعاع α (ألفا)** | إصدار نواة الهيليوم ₂He⁴ | الأنوية الثقيلة |
| **إشعاع β⁻ (بيتا سالب)** | انبعاث إلكترون ₋₁e⁰ | الأنوية الغنية بالنترونات |
| **إشعاع β⁺ (بيتا موجب)** | انبعاث بوزيترون ₊₁e⁰ | الأنوية الغنية بالبروتونات |
| **إشعاع γ (غاما)** | إشعاع كهرومغناطيسي غير مشحون | انتقال النواة من حالة مثارة إلى حالة أقل طاقة |

### 2.4 مخطط (N-Z) — Segré
يستخدم لتحديد نوع الإشعاع (α أو β⁻ أو β⁺) بناءً على موقع النواة بالنسبة لمنطقة الاستقرار.

### 2.5 التناقص الإشعاعي (النشاط الإشعاعي كظاهرة إحصائية عشوائية وتلقائية)
تناقص عدد الأنوية المشعة (أو كتلة العينة) بمرور الزمن وفق قانون أسي.

### 2.6 زمن عمر النصف وثابت الزمن
- **زمن عمر النصف (t½)**: الزمن اللازم لتفكك نصف العدد الابتدائي للأنوية المشعة.
- **ثابت الزمن (τ)**: متوسط عمر النواة، ويرتبط بثابت التفكك λ.

### 2.7 النشاط الإشعاعي A(t)
عدد التفككات التي تحدث في الثانية الواحدة، ويقاس بوحدة **البكريل (Bq)**.

### 2.8 التأريخ الإشعاعي (Radiometric dating)
استعمال قانون التناقص الإشعاعي (بدلالة N أو A) لتقدير عمر عينة (مثل تأريخ الكربون 14).

### 2.9 الطاقة النووية
- **وحدة الكتلة الذرية (uma)** ووحدة الطاقة (electron-volt، MeV).
- **تكافؤ الكتلة والطاقة** (مبدأ آينشتاين).
- **النقصان الكتلي (Δm)**: الفرق بين كتلة مكونات النواة منفصلة وكتلة النواة نفسها.
- **طاقة الربط (El)**: الطاقة الناتجة عن النقصان الكتلي؛ تقيس استقرار النواة.
- **طاقة الربط لكل نيوية (El/A)**: كلما كانت أكبر، كانت النواة أكثر استقرارًا.

### 2.10 التفاعلات النووية المستحثة
- **الانشطار النووي (Fission)**: انقسام نواة ثقيلة إلى نواتين أخف عند قذفها بنترون.
- **الاندماج النووي (Fusion)**: اتحاد نواتين خفيفتين لتشكيل نواة أثقل.
- **الطاقة المحررة من تفاعل نووي**: تُحسب من فرق الكتلة أو فرق طاقات الربط بين النواتج والمتفاعلات.

## 3. القوانين والعلاقات الرياضية (Laws & Formulas)

### 3.1 قوانين الانحفاظ في معادلة تفاعل نووي
- انحفاظ **العدد الكتلي (A)**.
- انحفاظ **العدد الذري (Z)**.

### 3.2 معادلات التفكك الإشعاعي
- **إشعاع α:**
  X₂ᴬ_Z → Y₂ᴬ⁻⁴_Z₋₂ + He₂⁴
- **إشعاع β⁻:**
  X₂ᴬ_Z → Y₂ᴬ_Z₊₁ + e₋₁⁰
- **إشعاع β⁺:**
  X₂ᴬ_Z → Y₂ᴬ_Z₋₁ + e₊₁⁰
- **إشعاع γ:**
  X*₂ᴬ_Z → X₂ᴬ_Z + γ₀⁰

### 3.3 قانون التناقص الإشعاعي
```
N(t) = N₀ · e^(−λt)
m(t) = m₀ · e^(−λt)
```
حيث:
- N: عدد الأنوية المتبقية في اللحظة t
- N₀: عدد الأنوية الابتدائية عند t = 0
- m, m₀: كتلة العينة عند t وعند t = 0 على التوالي
- λ: ثابت التفكك (بوحدة s⁻¹)

### 3.4 زمن عمر النصف
```
t½ = ln(2) / λ ≈ 0.693 / λ
```

### 3.5 ثابت الزمن
```
τ = 1 / λ
```

### 3.6 النشاط الإشعاعي
```
A(t) = λ · N(t)
A(t) = A₀ · e^(−λt)
```
حيث A₀ = λ·N₀ هو النشاط الابتدائي عند t = 0. وحدته: البكريل (Bq) = تفكك/ثانية.

### 3.7 علاقات التأريخ الإشعاعي
```
t = (1/λ) · ln(N₀/N) = (t½ / ln2) · ln(N₀/N)
t = (1/λ) · ln(A₀/A) = (t½ / ln2) · ln(A₀/A)
```

### 3.8 تكافؤ الكتلة - الطاقة
```
1 uma = 1.66054 × 10⁻²⁷ kg
1 eV = 1.6 × 10⁻¹⁹ J     ,     1 MeV = 10⁶ eV
1 uma ↔ 931.5 MeV
```

### 3.9 النقصان الكتلي
```
Δm = [Z·mp + N·mn] − mX
```
(مجموع كتل البروتونات والنترونات منفصلة، مطروحًا منه كتلة النواة X)

### 3.10 طاقة الربط
```
El = Δm · c²
```
طاقة الربط لكل نيوية:
```
El/A
```
(معيار استقرار النواة: كلما زادت هذه القيمة، زاد استقرار النواة)

### 3.11 الطاقة المحررة من تفاعل نووي
بدلالة الكتل:
```
|ΔE| = |Σm(نواتج) − Σm(متفاعلات)| · c²
```
بدلالة طاقات الربط:
```
|ΔE| = |ΣEl(نواتج) − ΣEl(متفاعلات)|
```

## 4. أمثلة التمارين المذكورة في الملخص

### مثال 1: الانشطار النووي
```
n₀¹ + U₉₂²³⁵ → Ba₅₆¹⁴¹ + Kr₃₆⁹² + 3 n₀¹
```
(نواة اليورانيوم 235 تنقسم بعد قذفها بنترون إلى الباريوم والكريبتون مع تحرر 3 نترونات)

### مثال 2: الاندماج النووي
```
H₁² + H₁³ → He₂⁴ + n₀¹
```
(اتحاد الديتيريوم والتريتيوم لتكوين الهيليوم وتحرير نترون)

> **ملاحظة:** الملف الأصلي لا يحتوي على تمارين تطبيقية محلولة كاملة (بأرقام وحسابات)، فقط معادلات نموذجية. يُنصح بإضافة تمارين رقمية محلولة كمصدر تكميلي لاحقًا (حساب t½، λ، النشاط، الطاقة المحررة بالأرقام).

## 5. المهارات المطلوبة (Skills)

يجب أن يكون الطالب قادرًا على:
1. كتابة رمز نواة وتحديد Z، A، N انطلاقًا منه.
2. التمييز بين نظيرين لنفس العنصر.
3. كتابة معادلة تفكك نووي (α، β⁻، β⁺) مع التحقق من قوانين الانحفاظ.
4. استعمال مخطط (N,Z) لتحديد نوع الإشعاع المتوقع لنواة معينة.
5. استغلال قانون التناقص الإشعاعي N(t) أو m(t) لحساب: λ، t½، أو الزمن t.
6. حساب النشاط الإشعاعي A(t) واستعماله في تمارين التأريخ.
7. حساب النقصان الكتلي Δm وطاقة الربط El وطاقة الربط لكل نيوية El/A.
8. مقارنة استقرار نواتين بالاعتماد على El/A.
9. كتابة وموازنة معادلات الانشطار والاندماج النووي.
10. حساب الطاقة المحررة من تفاعل نووي بطريقتين (بدلالة الكتل أو بدلالة طاقات الربط).
11. التحويل بين وحدات الكتلة والطاقة (uma ↔ kg ↔ MeV ↔ J).

## 6. الأخطاء الشائعة (Common Mistakes)

> ملاحظة: الملف الأصلي لا يذكر أخطاءً شائعة بشكل صريح. القائمة التالية مستنتجة من طبيعة الدرس ويجب التحقق منها أو تعديلها من قبل الأستاذ إذا لزم الأمر:

1. **الخلط بين β⁻ وβ⁺**: نسيان أن β⁻ يزيد Z بواحد (تناقص عدد النترونات) بينما β⁺ ينقص Z بواحد.
2. **عدم موازنة العدد الكتلي والعدد الذري** في معادلات التفكك أو التفاعلات النووية (خطأ في قوانين الانحفاظ).
3. **الخلط بين λ (ثابت التفكك) وt½ (عمر النصف) وτ (ثابت الزمن)** واستعمال العلاقة الخاطئة بينها.
4. **نسيان تحويل الوحدات** قبل التعويض في القوانين (خاصة uma إلى kg، أو MeV إلى J).
5. **الخلط بين النشاط الإشعاعي A(t) وعدد الأنوية N(t)** — A = λN وليسا نفس الكمية.
6. **حساب النقصان الكتلي بترتيب معكوس** (حساب mX − مجموع المكونات بدل العكس) مما يعطي إشارة سالبة خاطئة.
7. **الخلط بين طاقة الربط الكلية El وطاقة الربط لكل نيوية El/A** عند مقارنة استقرار نواتين مختلفتين في الحجم.
8. **عدم التمييز بين الانشطار والاندماج** من حيث نوع الأنوية المتفاعلة (ثقيلة تنقسم، خفيفة تندمج).
9. **إغفال إشعاع γ المرافق** الذي يصاحب غالبًا انبعاثات α أو β عندما تكون النواة الناتجة في حالة مثارة.

---

## 7. ملاحظات إضافية

- الوحدة المرجعية للنشاط الإشعاعي هي **البكريل (Bq)** = تفكك واحد في الثانية.
- استقرار النواة يرتبط بقيمة **El/A**: كلما زادت هذه النسبة، كانت النواة أكثر استقرارًا.
- تفاعلات الانشطار والاندماج كلاهما يحرران طاقة ضخمة مقارنة بالتفاعلات الكيميائية العادية، وذلك بسبب النقصان الكتلي الكبير نسبيًا وتكافؤ الكتلة-الطاقة.
