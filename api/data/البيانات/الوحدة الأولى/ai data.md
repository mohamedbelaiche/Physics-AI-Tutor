# الوحدة 01 – المتابعة الزمنية لتحول كيميائي في وسط مائي (BAC)

> مصدر: ملخص شامل BAC 2022 — منظم كمصدر معرفي (Source of Truth) للاستخدام من طرف نموذج الذكاء الاصطناعي.

---

## 1. المفهوم العام للدرس

الوحدة تتناول **المتابعة الزمنية لتحول كيميائي**، أي دراسة تطور تقدم التفاعل `x` بدلالة الزمن `t`، عبر طريقتين أساسيتين:
- **طريقة فيزيائية**: قياس الناقلية.
- **طريقة كيميائية**: المعايرة اللونية.

كما تتناول الوحدة **سرعة التفاعل**، **زمن نصف التفاعل t₁/₂**، و**العوامل الحركية** المؤثرة فيها (الحرارة، التراكيز، الوساطة).

---

## 2. التعريفات الأساسية

| المصطلح | التعريف |
|---|---|
| المؤكسد (Ox) | فرد كيميائي قادر على اكتساب إلكترون أو أكثر خلال تحول كيميائي |
| المرجع (Red) | فرد كيميائي قادر على فقدان إلكترون أو أكثر خلال تحول كيميائي |
| تفاعل الأكسدة | فقدان إلكترون أو أكثر من طرف المرجع |
| تفاعل الإرجاع | اكتساب إلكترون أو أكثر من طرف المؤكسد |
| تفاعل أكسدة-إرجاع | انتقال الإلكترونات من المرجع إلى المؤكسد (ثنائية Ox/Red) |
| المتفاعل المحدّ | المتفاعل الذي تنتهي كمية مادته قبل جميع المتفاعلات الأخرى |
| المزيج الستوكيومتري | يختفي فيه كل المتفاعلين كليًا في نفس اللحظة (نهاية التفاعل) |
| التحول الكيميائي السريع | يصل لحالته النهائية بمجرد تلامس المتفاعلات (لحظي) |
| التحول الكيميائي البطيء | يدوم من ثوانٍ إلى ساعات، يمكن متابعته بالعين المجردة |
| التحول الكيميائي البطيء جدًا | يدوم أيامًا إلى أشهر، تعتبر الجملة عاطلة كيميائيًا |
| زمن نصف التفاعل (t₁/₂) | المدة التي يبلغ فيها تقدم التفاعل x نصف قيمته العظمى xmax |
| العامل الحركي | كل ما يغيّر سرعة التفاعل (حرارة، تراكيز، وساطة) |
| الوسيط (Catalyseur) | نوع كيميائي يسرّع التفاعل دون التأثير على الحالة النهائية، ولا يظهر في معادلة التفاعل |
| أنواع الوساطة | متجانسة (نفس الطور)، غير متجانسة (طور مختلف)، أنزيمية (إنزيم) |
| عملية السّقي (Trempe) | تبريد مفاجئ للمزيج التفاعلي لإيقاف التفاعل |
| السّقي الفيزيائي | إضافة الأنبوب إلى ماء بارد+جليد (يؤثر على الحرارة فقط) |
| السّقي الكيميائي | إضافة ماء مثلج للأنبوب (يؤثر على الحرارة والتراكيز معًا) |
| التكافؤ (Équivalence) | النقطة التي يكون فيها المحلول المعايَر والمعايِر بنسب ستوكيومترية |
| مميزات تفاعل المعايرة | سريع، تام، ووحيد |

## 3. القوانين والعلاقات الرياضية

### 3.1 كمية المادة والتراكيز
```
n = m / M                    (n: مول, m: غرام, M: غ/مول)
n = C × V                    (C: مول/ل, V: لتر)
n = P·V / R·T                (غازات، R = 8.31 SI)
Vm = 22.4 L/mol               (شروط نظامية)
K(كالفن) = °C + 273
```

### 3.2 التركيز الكتلي، الكثافة، الكثافة النسبية
```
Cm = m / V = C × M
ρ = m / V                    (الكتلة الحجمية)
d = ρ / ρ_ماء                (سائل/صلب) ،  ρ_ماء = 1000 g/L
d = ρ_غاز / ρ_هواء = M_غاز / 29     (غاز) ، ρ_هواء = 1.29 g/L
```

### 3.3 التمديد (التخفيف)
```
C_مركز × V_مركز = C_ممدد × V_ممدد
F = C_مركز / C_ممدد = V_ممدد / V_مركز     (معامل التمديد)
```

### 3.4 النسبة المئوية الكتلية (درجة النقاوة) P
```
P = (m' / m) × 100                    (طريقة 1)
P = (C × M) / (10 × d_محلول)          (طريقة 2)
```

### 3.5 جدول التقدم (aA + bB = cC + dD)

| | aA | bB | cC | dD |
|---|---|---|---|---|
| ابتدائية (x=0) | n₀(A) | n₀(B) | 0 | 0 |
| انتقالية (x) | n₀(A) − a·x | n₀(B) − b·x | c·x | d·x |
| نهائية (xmax) | n₀(A) − a·xmax | n₀(B) − b·xmax | c·xmax | d·xmax |

- تحديد xmax: يُحسب لكل متفاعل: `xmax = n₀/معامله الستوكيومتري`، والقيمة الأصغر تحدد **المتفاعل المحدّ**.
- شرط المزيج الستوكيومتري: `n₀(A)/a = n₀(B)/b`.
- بما أن التفاعلات المدروسة تامة: `xmax = x النهائي`.

### 3.6 الناقلية
```
G = I / U = 1 / R                    (G: سيمنس, R: أوم)
σ = Σ λᵢ · [Xᵢ]                       (الناقلية النوعية)
G = K · σ = K · (Σ λᵢ · [Xᵢ])
K = S / L                             (ثابت الخلية)
```
⚠️ عند حساب الناقلية يجب مراعاة **الشوارد المتفرجة**.

### 3.7 سرعة التفاعل
```
v(t) = dx/dt                          (السرعة اللحظية للتفاعل)
v_vol(t) = (1/VT) × dx/dt             (السرعة الحجمية للتفاعل)

سرعة تشكل نوع: vC(t) = dn/dt          , vC_vol(t) = (1/VT)×dn/dt
سرعة اختفاء نوع: vA(t) = -dn/dt        , vA_vol(t) = -(1/VT)×dn/dt

العلاقة العامة: v = vA/a = vB/b = vC/c = vD/d
v_vol = vvol(A)/a = vvol(B)/b = vvol(C)/c = vvol(D)/d
```

### 3.8 زمن نصف التفاعل t₁/₂
```
t = t₁/₂  ⟹  x(t₁/₂) = xmax / 2
مدة التفاعل التقريبية ≈ 7 × t₁/₂
```

### 3.9 قواعد الاشتقاق الأساسية
```
d/dt(ثابت) = 0
d/dt(ثابت × متغير) = ثابت × d(متغير)/dt
d/dt(متغير/ثابت) = (1/ثابت) × d(متغير)/dt
d/dt(متغير ± ثابت) = ± d(متغير)/dt
```

## 4. المهارات المطلوبة

1. كتابة معادلات الأكسدة-الإرجاع باتباع الخطوات السبع (موازنة الذرات، ثم O بـH₂O، ثم H بـH⁺، ثم الشحنات بـe⁻، توحيد عدد الإلكترونات، اختزال الأنواع المشتركة، ذكر الحالة الفيزيائية).
2. بناء جدول التقدم وحساب xmax وتحديد المتفاعل المحدّ.
3. حساب التركيب المولي والتركيز المولي لأي فرد كيميائي عند لحظة معينة (ابتدائية/انتقالية/نهائية/t₁/₂).
4. التمييز بين طريقتي المتابعة الزمنية (الناقلية والمعايرة اللونية) ومتى تُستخدم كل واحدة.
5. اشتقاق العلاقات الرياضية للسرعة وزمن نصف التفاعل انطلاقًا من بيانات أو جداول التقدم (اتباع المراحل: 1) ربط المقدار بـx، 2) تطبيق الاشتقاق، 3) التعويض والحساب).
6. تحليل وتفسير تأثير العوامل الحركية (الحرارة، التراكيز، الوساطة) على سرعة التفاعل وعلى منحنى x(t).
7. إجراء حسابات التحضير والتمديد (من مسحوق أو من محلول مركز) وتطبيق بروتوكولات المخبر.
8. رسم وتحليل منحنى x(t) واستخراج xmax وt₁/₂ بيانيًا.

## 5. أمثلة أسئلة/تمارين شائعة (نموذجية في الامتحانات)

- لماذا يجب إضافة الأنبوب إلى (ماء بارد + جليد) قبل المعايرة؟ → لإيقاف التفاعل.
- عرّف عملية السّقي واذكر نوعيها، وهل تؤثر على حجم التكافؤ؟ → لا تؤثر، لأن كمية المادة لا تتغير.
- ما مميزات (خواص) تفاعل المعايرة؟ → سريع، تام، ووحيد.
- عرّف التكافؤ، وكيف نستدل على حدوثه؟ → بتغيّر لون المحلول.
- اذكر خطوات البروتوكول التجريبي لعملية المعايرة اللونية.
- ارسم التجهيز المناسب لعملية المعايرة اللونية.
- هل يتطور محتوى الأنابيب بنفس طريقة تطور محتوى البيشر الأصلي؟ → نعم.
- إثبات علاقات السرعة أو t₁/₂ انطلاقًا من جدول التقدم وبيان تجريبي (تمرين حسابي/اشتقاقي كلاسيكي).
- تمارين حساب xmax وتحديد المتفاعل المحدّ من معطيات كمية المادة الابتدائية.
- تمارين تفسير تأثير تغيير درجة الحرارة أو التركيز على منحنيين x(t) لتفاعلين مختلفين.

## 6. أخطاء شائعة يجب الانتباه لها

- ❌ نسيان حساب تركيز/مساهمة **الشوارد المتفرجة** عند حساب الناقلية أو التركيز المولي.
- ❌ الخلط بين تأثير الحرارة/الوساطة (**لا تغيّر** التركيب المولي النهائي) وتأثير التراكيز (**تغيّر** التركيب النهائي).
- ❌ الخلط بين السّقي الفيزيائي (يؤثر على الحرارة فقط) والسّقي الكيميائي (يؤثر على الحرارة والتراكيز معًا).
- ❌ عدم اتباع الترتيب الصحيح في موازنة معادلات الأكسدة-الإرجاع (الذرات → O بـH₂O → H بـH⁺ → الشحنات بـe⁻).
- ❌ الاعتقاد الخاطئ بأن عملية السّقي (فيزيائيًا أو كيميائيًا) تؤثر على حجم التكافؤ VE — وهذا خطأ، لأن كمية المادة لا تتغير.
- ❌ الخلط بين xmax (التقدم الأعظمي النظري) والتقدم النهائي الفعلي — في هذه الوحدة كلاهما متساويان لأن التفاعلات تامة، لكن يجب توضيح السبب لا افتراضه.
- ❌ نسيان الحالة الفيزيائية للأنواع الكيميائية عند كتابة المعادلات.
- ❌ الخطأ في تحديد المتفاعل المحدّ باختيار القيمة الأكبر بدلًا من **الأصغر** لـxmax.

## 7. المتطلبات السابقة (مكتسبات السنة أولى وثانية ثانوي)

- قوانين كمية المادة الأساسية: `n = m/M`، `n = C×V`، قانون الغازات المثالية `n = PV/RT`.
- مفاهيم التركيز المولي، التركيز الكتلي، الكثافة، والكثافة النسبية (d).
- قانون التمديد (مبدأ الحفاظ على كمية المادة أثناء التخفيف).
- أساسيات كتابة وموازنة المعادلات الكيميائية.
- المبادئ الأساسية للقياسات الكهربائية (شدة التيار I، التوتر U، المقاومة R) لفهم قانون الناقلية.
- أساسيات الاشتقاق الرياضي (مطلوبة لاستنتاج عبارات السرعة وزمن نصف التفاعل).
- معرفة وحدات القياس وتحويلاتها (الكتلة، الحجم، التركيز، الضغط، الحرارة) — انظر الجدول أدناه.
